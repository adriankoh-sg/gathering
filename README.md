# Gathering 
Gathering is an App to allow people to create a family, friends, members gathering for an event and RSVP via mobile. RSVP will recieve notification and response accordingly.

Optional feature is also available for attendance taking on actual day.

## Project Description

This project is created using a `nextjs` full-stack framework with React.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

`src/app` - main app router.     
`src/app/api` - APIs for external usage (future implementation).    
`src/app/dashboard` - Admin dashboard for admin to create gatherings, rsvp members management and etc.    
`src/lib` - libraries functions and constants.
